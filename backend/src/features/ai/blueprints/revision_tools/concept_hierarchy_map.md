# Concept Hierarchy & Mindmap Blueprint

## Metadata
- **Type Key**: `concept-map`
- **Aliases**: `concept map`, `mindmap`, `hierarchy`, `tree diagram`, `taxonomy`, `branching map`
- **UI Category**: `visual` / `interactive`

## Data Schema
```json
{
  "id": "1",
  "front": "Parent Category / Domain",
  "back": "Sub-branches, child concepts, operational mechanisms, and dependencies."
}
```

## Interactive Mechanics
1. Hierarchical nodes organized by parent and child relationships.
2. Interactive node expansion/collapse on click.
3. Summary panel showing detailed descriptions and definitions of the selected node.
