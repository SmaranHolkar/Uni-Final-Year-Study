# Word Search Discovery Matrix Blueprint

## Metadata
- **Type Key**: `word-search`
- **Aliases**: `word search`, `wordsearch`, `word puzzle`, `letter matrix`, `spelling search`
- **UI Category**: `interactive` / `grid`

## Data Schema
```json
{
  "id": "1",
  "word": "HOMEOSTASIS",
  "hint": "The state of steady internal, physical, and chemical conditions maintained by living systems."
}
```

## Interactive Mechanics
1. **Interactive Word Cloud / Matrix**: Discoverable terms with clue cards.
2. **Click-to-Review**: Clicking any badge marks it as discovered/found and displays detailed definitions.
3. **Progress Bar**: Tracks the proportion of vocabulary terms unlocked.
