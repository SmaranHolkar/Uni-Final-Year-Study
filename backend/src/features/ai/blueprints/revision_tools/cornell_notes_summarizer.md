# Structured Cornell Notes Study Sheet Blueprint

## Metadata
- **Type Key**: `cornell-notes`
- **Aliases**: `cornell notes`, `study notes`, `lecture summary`, `cue notes`, `study sheet`
- **UI Category**: `list` / `cards`

## Data Schema
```json
{
  "id": "1",
  "front": "Cue Question / Key Keyword",
  "back": "Detailed lecture notes, explanations, examples, and summary synthesis."
}
```

## Interactive Mechanics
1. Authentic 3-part layout (Cue Column, Main Notes Column, Summary Footer).
2. Foldable/Toggleable Cue mode to test active recall before revealing notes.
3. Fast search and highlight filter.
